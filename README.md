# libbox-apple

Builds [sing-box](https://github.com/SagerNet/sing-box)'s `Libbox.xcframework` (iOS device + simulator) from an
upstream release tag with a reduced feature set for a small iOS packet-tunnel extension, and publishes it as a
GitHub release asset. Run the `libbox` workflow with the sing-box version. sing-box is GPL-3.0; this repo only
holds the build workflow.
